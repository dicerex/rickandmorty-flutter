# Rick and Morty

Небольшой каталог на Flutter / Dart. Поиск по имени с задержкой 400 мс,
постраничная загрузка при прокрутке, детали персонажа и повтор запроса при ошибке.
Тёмная тема, адаптивная сетка. Интерфейс на русском; имена и локации приходят из API.

## Запуск

Нужен Flutter 3.41+ (Dart 3.10+).

```sh
flutter pub get
flutter run -d chrome
```

Также созданы проекты Android и iOS. Для iOS на устройстве выберите свою команду
подписи в Xcode. Android требует установленный Android SDK.

## Устройство проекта

- `lib/data` — REST-клиент на http, разбор страниц и обработка 404.
- `lib/models` — модель персонажа.
- `lib/controllers` — ChangeNotifier: поиск, страницы, ошибки, защита от устаревших ответов.
- `lib/screens` — каталог и детали.
- `lib/widgets` — изображение с заглушкой и статус.

Детали используют данные из списка: дополнительный запрос не нужен.
При переходе открывается новый маршрут; каталог, строка поиска и ScrollController
остаются в памяти. После возврата сохраняются поиск, загруженные страницы и прокрутка.
После перезапуска приложения состояние сбрасывается. Офлайн-хранилище не предусмотрено.

API: https://rickandmortyapi.com/documentation

## Проверка

```sh
flutter analyze
flutter test
flutter build web
```

Тесты проверяют повтор неудачной страницы, сохранение загруженных данных,
игнорирование устаревшего ответа поиска и пустой результат при 404.
